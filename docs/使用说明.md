# Supervision Circle 使用说明

## 先保存两个不同的链接

首次创建小组后，保存完整的 **Management link（管理链接）**，包括 `#admin=` 后的内容。管理链接只由组织者保管，建议存入自己的书签或密码管理器；换设备时用它进入管理页面。

点击共享栏的 **Copy link** 复制 **Shared link（共享链接）**，放进给导师的邀请中。它包含 `#key=`，五个人一直用同一条共享链接，每个月不需要换。导师无需注册或登录，选择姓名即可填写。

管理入口不会出现在导师的共享页面中。浏览器记住姓名只是方便使用，不是身份验证。请只把共享链接发给本小组。

## 每月操作

1. 打开管理链接，点击 **New month**，选择会议月份和回复截止时间，创建草稿。
2. 添加约 6–8 个候选时间。每次 45 分钟，工作日 09:00–17:00，开始时间按 15 分钟递增；最晚 16:15 开始。可以加入第三个星期二 16:00 的原定时段，它不会获得推荐优先权。
3. 检查时区和截止时间，点击 **Open poll** 发布。草稿只在管理页可见。
4. 复制邀请文案，在 Outlook 邮件中粘贴并群发。文案包含共享链接。
5. 你自己也需要选择姓名并填写；你是五位参与者之一。
6. 查看完整投票表和推荐，必要时复制提醒或特定时间的确认文案，联系尚未回复或需要协调的人。
7. 点击 **Choose this time** 或 **Review this option**，检查每个人的情况，再确定时间。你自己的回复必须是 Best 或 Available。
8. 网页显示时间已选定，等待你更新 Outlook。打开现有重复会议，修改对应月份的那一次并发送更新；完成后在网页标记 **I’ve sent the Outlook invite**。

截止时间只提示逾期，不会关闭投票，也不会将空白变成拒绝。选定时间之后才锁定；管理页可以 **Reopen poll** 重新开放并保留旧回复。已经发过 Outlook 邀请的会议重新选时间后，还需要再次更新 Outlook。

## 导师如何填写和修改

1. 打开共享链接，选择自己的姓名。
2. 在自己的填写区域，对每个候选选择一个选项：

| 选项 | 意思 |
| --- | --- |
| Best | 最方便，优先选这个 |
| Available | 可以参加 |
| Need to check | 需要先协调安排，还不能确认 |
| Unavailable | 不能参加 |
| No response | 尚未回复，与不能参加不同 |

3. 保存回复，看到成功提示后即可关闭网页。保存失败时输入会保留，可以重试。
4. 以后重新打开链接、选择同一个姓名，就可以修改。换设备后重新选姓名；数据从服务器读取。
5. 如有更好时间，点击 **Suggest a time** 添加。新候选会加入同一张表；其他人只需要补填新增时段，旧回复保留。

Outlook 显示 Busy 不能代表一定不能开会。请根据真实情况选择 Available 或 Need to check；网站不会自动读取或判断日历。

电脑使用紧凑表格；手机的个人回复按候选显示，完整五人表格可横向滚动。多人页面会定期刷新，也可以手动刷新获取最新结果。

## 怎样读推荐

- **Everyone can attend**：五个人都选择 Best 或 Available。Best 更多的排在前面，同分按时间先后。
- **Needs coordination**：没有明确缺席的人，但有人 Need to check 或 No response。页面列出具体人数和姓名，不代表全员确认。
- **Alternatives with absences**：至少一人 Unavailable，列明谁不能参加。优先继续寻找共同时间；是否接受缺席由组织者明确决定。

**Complete** 表示这个人填完当前候选；**Needs update** 表示曾经填过，但新增候选还没补全；**Not started** 表示还未开始。

## 改名单、时区和候选

管理页右上角齿轮打开 **Circle settings**：修改会议名称、五人姓名、默认时区。第一位是组织者。姓名修改保留已有回复，因此用于更正名字，不适合把原成员直接替换成另一人；换人时建议创建新小组。

更改默认时区仅影响之后新建的月份，已有月份的时间不会移动。每月时区按日期正确处理夏令时。

已发布的候选时间不能带着原票直接改时间。删除旧候选并添加新时间，重新收集意见。重复添加同一个时段不会多出一行。

## 常见问题

- **打开后没有投票**：确认管理员已经发布草稿，并且复制了完整共享链接，包括 `#key=` 后的部分。
- **没有管理按钮**：打开你保存的完整管理链接。共享链接没有管理权限。
- **提示别人修改过同一回复**：先查看最新结果，再重新修改；这是为了防止过期页面覆盖更新。
- **导师打不开或被要求登录**：检查托管网站的访问权限是否为公开。小组仍通过共享链接的密钥区分访问权限。
- **确定时间后 Outlook 没变化**：这是预期行为，仍需你手动修改或发送正式邀请。
- **管理链接丢失**：先查书签和创建时使用的浏览器。本版没有邮箱登录或自动找回流程。

You can suggest additional times, and edit your replies later using the same link. I will confirm the selected time with an Outlook invitation.
